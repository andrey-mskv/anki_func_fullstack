# Anki Func Fullstack

Консольное приложение для изучения иностранных слов.  
Программа позволяет создавать собственный словарь, тренировать перевод слов и отслеживать результаты игры.

## Возможности

- Загрузка словаря из текстового файла.
- Добавление новых слов и переводов.
- Проверка перевода введённого слова.
- Случайный порядок слов в игре.
- Отсутствие повторов слов в пределах одного игрового круга.
- Подсчёт количества правильных ответов.
- Подсчёт общего времени игры.
- Расчёт среднего времени ответа.
- Режим тренировки до первой ошибки.
- Просмотр всех слов и переводов.
- Сохранение словаря в файл.
- Возможность завершить игру командой `СТОП`.

## Меню

После запуска приложения отображается главное меню:

```text
Меню:
1. Начать игру
2. Добавить слова
3. Тренировка до первой ошибки
4. Вывод всех слов
5. Выход
```

## Игровой процесс

### 1. Начать игру

Программа показывает слово, пользователь вводит перевод. За правильный ответ — очко. После ошибки показывается правильный перевод.

### 2. Добавить слова

Добавление новых пар "слово → перевод". Проверка на дубликаты без учёта регистра.

### 3. Тренировка до первой ошибки

Правильный ответ — очко, неправильный — завершение тренировки.

### 4. Вывод всех слов

Отображение всех пар из словаря.

### 5. Выход

Сохранение словаря и завершение работы.

## Статистика

После игры выводится:

- Количество правильных ответов
- Общее время игры

- Среднее время ответа

## Формат словаря

Файл words.txt - слово,перевод

```text
translation,перевод
apple,яблоко
morning,утро
```

## Основные функции

| Функция | Назначение |
| --- | --- |
| load_words() | Загрузка словаря |
| save_words() | Сохранение словаря |
| add_words() | Добавление слов |
| play_game() | Игровая логика |
| start_game() | Обычный режим |
| train_until_mistake() | Тренировка до ошибки |
